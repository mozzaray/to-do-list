# To-Do List 
A simple side project of a to-do list.

This project uses Vue 3 + Taiwind CSS to render a to-do list web application.
Features:
- Insert and delete tasks
- Mark done tasks
- Responsive website

## Tech Stack
- Vue 3
- Vite
- Tailwind CSS

- 1.0.0
